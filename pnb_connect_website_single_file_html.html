      Quick Integration Tips

      • Expose a REST API on a trusted server to run VM and scan actions.
      • Authenticate (OAuth2 / API keys) and audit commands before execution.
      • Use websockets for live progress updates during scans or VM creation.
      • Run privileged operations in an isolated environment (containers / VMs).
